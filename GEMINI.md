# Guidelines for Gemini (AI Assistant)

This document outlines the rules and philosophy to follow when working on the Swarm OS project.

## Task Management
- **Check Design & TODO**: Before starting any tasks, you MUST read the `DESIGN.md` and `TODO.md` files to understand the current plan and state.
- **Update `TODO.md`**: After completing each task or phase, you MUST update `TODO.md` in the workspace to reflect the progress.
- **Always Update TODO at the end**: At the end of each turn, you MUST ensure `TODO.md` is updated to reflect the latest state, even if a task is still in progress.

## Design Documentation
- **Update `DESIGN.md`**: If any implementation decisions deviate from the design or if new components are added that require architectural documentation, you MUST update `DESIGN.md` accordingly.

## Philosophy
- **Simplicity First**: Do simple but working things first. Add complexity only when strictly necessary. Avoid over-engineering or building features that are not immediately required by the current phase.
